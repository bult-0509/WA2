# WEMOVE UI 实施基线

内部设计准备，尚未形成高保真设计稿。依据为详细需求第 13 章及附录 E，真实品牌资产取得后再核对配色。

## 视觉依据

面向家长、成年消费者和采购人员，白色／浅中性色背景、清晰无衬线字体、真实产品和家庭场景摄影，使用留白而非大量装饰。避免杂乱卡通、高饱和多色、频繁视差和持续自动播放。

ui-ux-pro-max 首次查询 sports toys brand catalog 返回运动粉丝型红色方案；收窄为 product catalog minimal neutral 后仍出现药房绿色配色。两套完整方案均未通过适配检查，没有按匹配成功的品牌方案保存。本文件回退到需求书和技能内置通用规则。error summary validation 的 Web 表单错误汇总规则匹配成功，可直接用于表单设计。

## 暂定设计变量

| 变量 | 值 | 用途 |
| --- | --- | --- |
| 背景／分区 | #FFFFFF / #F5F7FA | 主背景与轻分区 |
| 正文／次要 | #182536 / #526071 | 信息层次 |
| 主色／按钮文字 | #183B56 / #FFFFFF | 品牌资产未确认前的暂定信息色 |
| 边界／焦点 | #D6DEE8 / #176BBD | 边界和键盘焦点，实际控件需单独检查对比度 |
| 错误／成功 | #B42318 / #166534 | 同时配合文本，不能仅依赖颜色 |
| 字体 | system-ui、Segoe UI、Microsoft YaHei、sans-serif | 本地运行不依赖外部字体请求 |
| 正文 | 16px，行高 1.5—1.7 | 长文保持可读行长 |
| 间距 | 4、8、12、16、24、32、48、64px | 共用尺度 |
| 圆角 | 控件 8px，卡片 12px | 统一适度圆角 |
| 反馈动效 | 150—200ms | 支持 prefers-reduced-motion |

以上是实施建议，不是官方品牌规范。正文对比度至少 4.5:1，焦点和控件边界需实测。产品强调色取自真实素材，不伪造认证、销量、评价或规格。

## 代表模板与状态

| 模板 | 结构 | 必须处理的状态 |
| --- | --- | --- |
| 首页 | 真实场景 Hero、1—2 CTA、分类、精选产品、玩法、事实型品牌价值、经销商、支持与订阅 | 缺素材时在设计记录标记，不展示虚构数据 |
| 产品列表 | 面包屑、分类说明、结果数、筛选、排序、卡片、分页 | 加载、无结果、失败、清除筛选、URL 恢复 |
| 产品详情 | 画廊、名称／SKU／年龄、变体、角色 CTA、规格、玩法、安全、下载、FAQ | 停售、缺货、区域不可售、无价格权限 |
| 经销商中心 | 任务、授权目录、快速订货、报价、订单、资料、企业 | 待审、补件、暂停、无权限、逐行数量错误 |
| 后台商品 | 侧栏、筛选表格、编辑、发布校验、历史 | 草稿、预约、发布、归档、保存失败、冲突 |

后台及经销商中心强调任务效率，不复制官网大幅 Hero。公开页面默认英文，后台可配置语言；内部工程状态页可用中文，不属于最终官网模板。

## 交互与响应式

阶段记录（2026-09-04）：已实现首页、目录、单图详情、联系表单、品牌介绍和后台商品／询盘／首页文案／审计界面。首页抽象图形只是开发装饰，文案待品牌审核，全站标注 LOCAL PREVIEW，没有填充虚构商品。当前列表直接展开筛选；后台三态、移动横向导航与单列表单已实现。媒体画廊、筛选抽屉、通用 CMS、经销商模板及全尺寸兼容验收仍待后续完成。此记录不替代完整设计目标。

语言记录（2026-09-07）：官网、联系表单、登录页与主要后台界面支持 English／中文切换，使用同一组紧凑文字按钮并显示当前选择。偏好跨页面保存，`html lang` 随语言更新。后台录入的品牌和商品正文保持原文，避免把未经审核的机器翻译当作正式内容；后续内容模型需增加独立语言版本。

按钮有主次、危险、加载和禁用状态。SVG 图标风格一致，有可访问名称，不用 emoji 作为控件图标。触控目标至少 44×44px。提交保留输入、防重复点击，成功与失败都要真实反馈。

表单使用可见标签和字段附近错误，通过 aria-describedby 关联。长表单提交失败后聚焦顶部错误汇总，并提供跳至字段的链接，不在每次失焦时抢焦点。经销商申请分步保存草稿；上传显示文件名、大小、进度和删除入口。

抽屉／弹窗管理进入焦点、焦点范围、Esc 关闭和返回焦点。拖拽排序提供键盘上移／下移替代。移动筛选使用抽屉并展示已选条件和结果数。

小于 768px 单列为主，768—1199px 产品 2—3 列，1200px 以上 3—4 列；内容最大宽建议 1280px。采购表和比较表使用固定标识列或逐项卡片。检查 360、390、768、1024、1440、1920px，以及长文、空／错／加载、缩放、键盘和 reduced-motion。未实测不得标记通过。
